# muntaha-janu

A little something for Muntaha.

Six screens: envelope, hello, photos, reasons, the ask, and the yes.

## Making it yours

- **Photos** - add `photo1.jpg`, `photo2.jpg`, `photo3.jpg` to `images/`
- **Song** - add `song.mp3` to `music/`
- **Words** - every line lives in `index.html`; the bits worth changing are marked `EDIT ME`

Open `index.html` to preview locally. Live at
https://syedbilal1997.github.io/muntaha-janu/
